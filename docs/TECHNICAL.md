# 기술 설명

- 대상 게임 코드 BGKJ, 원문 CP932. 절대 ROM 포인터를 검증한 뒤 번역을 확장 영역으로 재배치합니다.
- 장면 스크립트 103개 블록, 대사 출현 2,638곳, 고유 번역 1,252줄을 반영합니다. 원본 명령·제어 흐름과 닫는 명령을 유지합니다.
- 기존 글리프 4,379개에 번역 글리프 826개를 추가해 5,205개 테이블을 사용합니다. 본문은 16×14 원본 셀 안에 갈무리11 픽셀을 그대로 넣고, 양쪽 8픽셀 영역을 읽습니다.
- 본문 글자 진행 12픽셀, 공백 6픽셀. 공백 처리와 타자 출력 루틴을 함께 수정합니다.
- 메뉴는 타일·팔레트·객체 좌표를 유지하며, 상태·동료·도감과 타이틀에 그린 글자를 적용합니다. 레벨 상승과 게임 종료의 공유 글리프·객체 순서를 보정했습니다.
- 세 타이틀 경로를 수정하고 전경 장식이 ‘열도’를 가리지 않도록 겹침을 처리했습니다.
- `data/`에는 추출용 주소·길이 및 레이아웃 메타데이터만 둡니다. `assets/`는 새로 만든 글자와 패치에 쓰는 간판 영역입니다.
- 런타임 입력·프레임 수집용 훅과 진행 조건 조작은 검증용 메모리에만 적용했습니다. 배포 ROM에 디버그 훅은 포함하지 않습니다.
