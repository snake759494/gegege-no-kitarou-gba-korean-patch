고정 능력/동료 표찰 `820EB4`와 이야기/도전 팝업 `8364D4`는 정적 참조만으로 실사용이라고 판단하지 않았습니다. 원본 실행 경로와 sprite 호출을 추적했습니다. 전자는 지형 인덱스 선택 1,280가지 및 상태 스프라이트 목록에서 도달하지 않았고, 후자는 버튼·기록·페이즈 조합 4,296가지에서 해당 자식 객체가 그려지지 않았습니다. 실제 일반/EX 선택 자원은 `842888`입니다. 검증한 정상 경로에서 두 자원은 표시되지 않는 잔존 자원으로 판단했습니다.

## 한계

정상 조작으로 이동·전투·수집·모든 분기를 수행한 전체 완주와 실제 GBA 기기 검증은 하지 않았습니다. 장면 호출과 조건 준비는 분기 선택에 따른 모든 플레이 과정의 검증을 대신하지 않습니다. 미등록 글리프·일본어 0은 검사한 대사/화면 범위의 결과이며 모든 가능한 실행 상태의 부재 증명은 아닙니다.

게임 메모리 덤프·원본 자원 이미지·전체 원문 추출물·개인 경로가 포함된 원시 실행 기록은 공개하지 않습니다. 공개 문서는 최종 빌드에 묶인 결과 요약이며 재검토용 소스 도구를 함께 제공합니다. 검증 후 VBA를 모두 종료했고 원본 ROM·기존 저장·설정을 보존했습니다.
